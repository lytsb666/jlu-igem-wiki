# 2026-10-18 可独立撤回的图片显示层

本目录对应用户要求：在不影响内容和观看效果的前提下，收紧图片纯色空边、融合纸白背景，并能只撤回这部分处理。

- `profile.json`：141 份已检查原图的路径、SHA-256、原尺寸、显示窗口及背景处理类型；原图仍位于各自原有目录，没有覆盖或改写。
- `entries.js`：同一清单的构建资源绑定，使开发预览和发布后的带哈希资源都能正确匹配。
- `settings.json`：独立启停开关。停用只恢复本轮图片裁切、背景融合及图片外层空白框的原显示，不撤回正文、图表注或 Back 修改。

100 个裁切候选只收紧外围空白，保留安全边距；已有科研图显示窗口与候选窗口求交，避免重复裁切。原有 Hardware 专用窗口保留。第一代 iHP 两张设备图保留明确要求的同高布局。候选数不等于每页实际新裁切数，部分已有窗口已经足够紧。

133 份纸白背景候选使用浏览器 SVG 显示滤镜；非白色源像素保持原色，检测到的彩色区域白色前景单独保护。Contribution 第一张原理图带 252–255 的近白纸纹，单独使用更紧的显示窗口和近白背景处理。原图放大入口仍打开完整原件。

不对人物照片、首页叙事、封面、浮动人物等执行背景移除；安全页嵌入实验室照片的拼图也保留照片色彩。四张 Model 机制图的白色标题及彩色底板沿用原显示 SVG，不套纸白滤镜。曲线、坐标、图例和表格文字保留，不重绘科研内容。
