# 页脚赞助商高清修复 · 2026-10-16

用户明确要求全部 sponsor 提高清晰度，保持现有格式与显示大小。本目录保存七个高清衍生 PNG 和实际展示的 SVG，旧原件及旧透明版均保留。

- 模式：内置 `image_gen.imagegen`，使用已有原始标志做修复，不使用 CLI/API fallback；每个标志独立处理，输出透明背景。
- 完整提示词、原件路径与 SHA-256、生成图尺寸／SHA-256、显示尺寸和处理方式在 [restoration-manifest.json](restoration-manifest.json)。提示词要求保持原名称、图形、比例、颜色与透明背景，去压缩噪点和毛边。
- SVG 保持旧版相同的固有宽高比，通过原生 SVG 清理透明边缘与字形中的小孔洞，校正回原品牌的蓝、绿、红灰、白等墨色，不保留修复产生的浅色边缘。
- 公共卫生学院仅采用修复后的大字部分，圆形校徽沿用原件，以保留原有微小文字与年份。
- 生命科学学院保留原件的深灰中文、浅灰英文和绿蓝图形；原英文名称用同样内容的 SVG 文字展示，避免小字被位图放大弄糊。生工的原注册标记使用标准 SVG 文字符号显示。
- 七个 `.svg` 是页脚实际使用版本；同名 `.png` 是修复输入，部分细节经上述 SVG 显示层修正。页面无需依赖生成缓存或外部附件路径。
