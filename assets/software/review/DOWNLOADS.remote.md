Both team-supplied APKs are preserved byte-for-byte. Generation labels are based on their application IDs matching the corresponding source projects; the `(2)` suffix in the supplied filename is not a generation identifier.

Install it on a compatible Android device. Connect to a network that can reach the AI Box, enter the device's actual IP address and port, and connect. Image acquisition, temperature updates, and hardware controls require the corresponding device server. The APK does not provide an offline demo workflow.

The source projects remain available in the repository root. See the root README for build instructions and `docs/PROTOCOL.md` for the device protocol.
