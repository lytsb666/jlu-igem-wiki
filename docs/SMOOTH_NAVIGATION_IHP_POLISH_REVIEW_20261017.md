## 页内滑动

- `directory-navigation.js` 从目录专用扩展为同页锚点共享导航，覆盖目录、五问题／四步骤图入口、正文链接、引用角标、Team 封面入口及指向当前页面的带锚点链接；兼容 `.html` 与无后缀地址。跨页、不同查询上下文、下载、外部网站、修饰键和新窗口行为保持。
- 普通模式采用 420–1050ms 的分段三次缓入缓出。动画过程中重算目标位置；图片、披露或手机目录高度变化时，从当前位置平滑修正，避免最后硬跳。每帧的即时坐标是动画采样，不是一次性跳到终点。
- 沿用一次页首避让、目标展开、焦点、地址锚点及目录稳定跟随；支持另一 Model 模块内目标并保留所选锚点。第二次点击取代第一次，滚轮、触屏、指针与键盘输入停止程序滚动；减少动态设置直接定位。
- 移除 iHP 五问题原独立即时校准器，原稿点击只负责揭示目标，统一由共享导航滑动，防止两套滚动争夺位置。历史进入／返回的原页面逻辑保持。
- 手机正常动态核查发现旧反思转盘旋转时产生约 10px 横向溢出，针对其容器增加 `overflow-x: clip`，保留转盘运动及内部阅读、避免整页横向移动。
