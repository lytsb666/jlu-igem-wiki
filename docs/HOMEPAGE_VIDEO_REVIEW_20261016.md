# 2026-10-16 首页计时与视频图注

本轮为本地开发，用户要求机器场景刚滚入视野时开始倒计时、所有视频无上下图注，并提出大白边图片方案。保留此前未提交成果，没有上传或发布。

## 实施

- `样式/home-story.js`：观察目标由 `.workflow-timer` 改为整个 `.home-chapter--workflow`，场景出现第一段可见区域即开始计时，启动后解除观察；不再等位于画面中间、稍后淡入的数字图层到达。首次进入前为 30:00，之后实际时间、回滚继续和 30 分钟循环保持。
- 视频核查：当前本地预览的 Hardware 三段、Contribution 一段正文视频均已无原图注；Homepage 官方嵌入播放器也无网页图注。用户回复“你检查没有就行”，未指定额外的残留位置。
- `样式/captions.js`：把视频图注清理集中在公共图注处理前，覆盖播放器内及紧邻上／下方的已标记图注、动态插入视频／图注和首页官方 iframe。保留普通章节标题、正文、图片表格说明、辅助技术标签和播放按钮。删除 `preview-format.js` 原先只处理初始 `figure > figcaption` 的局部逻辑。
- 白边只做只读初筛并形成 [方案](IMAGE_WHITE_MARGIN_PLAN_20261016.md)；没有修改原图或批量应用裁切。
