# 2026-10-16 Homepage 倒计时漏触发修复与三倍速

上一轮版本已由 [PR #9](https://github.com/lytsb666/jlu-igem-wiki/pull/9) 合并、部署。用户反馈首页倒计时不动，随后明确要求进入机器场景瞬间开始、3 倍速播放。本轮修复这个已发布功能，继续更新原固定网站，不扩展到其他页面或暂缓事项。

## 原因与改动

- 在线上 1440px／390px 复现：竖向场景条使下一场景长时间停在视口边缘；IntersectionObserver 先报告 `isIntersecting=true`、交集高度为 0，被旧条件过滤。继续滚到实际可见时没有新通知，倒计时一直停在 30:00。之前仅跳到已有正可见面积的位置核查，漏测了该边界路径。
- `样式/home-story.js`：启动改接现有叙事时间线中机器场景实际到达且素材已就绪的分支；启动函数只执行一次。不再依赖 IntersectionObserver，也不会在前一场景停留期间提前开始。
- 数字图层从场景到达时直接显示，不再等待原局部进度 28%–46% 淡入。保留原暖色数码管、透视、机器图片及其他动画。
- 以实际经过时间的 3 倍计算剩余时间，每 100ms 检查、仅数字改变时更新文字和可见 SVG。实际 1 秒走显示 3 秒，实际 600 秒完成显示 30 分钟后循环；离开和返回场景继续，不重置。`homepage/index.html` 同步辅助技术名称。
- 全局第 24 节保存最新要求；其他页面、iHP 图注暂缓、Summary 留空、缺失 PDF 和白边仅方案均保持。

## 验证

- 本地 Chrome／Playwright：1440×900、390×844 完整重现零高度边界；前一场景停留时保持 30:00，机器场景刚出现约 1px 时立即具备完整数字图层，实际一秒后显示 29:57。
- 对照每位数码管的可见 SVG 段和文字，确认两者同步变化；桌面、手机及桌面减少动态模式均通过。减少动态模式直接跳入场景也可启动。
- 受控时间验证实际 599 秒显示 00:03、600 秒循环回 30:00、601 秒显示 29:57；回滚后返回不重置。另以真实时间等待约 1.2 秒，显示减少 3 秒，确认停留不滚动时也持续更新。
- 桌面／手机截图已核对数码管位置；各受测场景无页面脚本错误。浏览器辅助脚本对减少动态模式的无滤镜状态兼容后通过，未因此变更网页。
- `npm run build` 与 `scripts/check-build.mjs` 通过：885 文件、23 HTML、1749 引用，最大资源 22,559,008 bytes，缺失／超限／不安全项为零。
- 调试脚本、原故障记录、针对性检查及截图保存在忽略的 `.local/countdown-edge-20261016/`；本文件保存可接手的结论。
